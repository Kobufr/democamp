# こもれびキャンプ

全国の実在キャンプ場83か所をモチーフにした、非公式の3Dキャンプゲームです。地形・施設・属性・地点はゲーム向けの概略で、営業・予約情報ではありません。

## 技術構成

- ブラウザ：JavaScript ES Modules / HTML / CSS、Three.js。WebGL非対応環境にはCanvas描画のフォールバック。
- サーバー：TypeScript、Vinext、Cloudflare Workers。
- DB：Cloudflare D1（SQLite）、Drizzleでスキーマとマイグレーションを管理。
- 認証：Sites標準のChatGPTログイン。外部のGoogle OAuthを直接接続する機能は、このホスティングでは未対応です。

## 利用

ゲストはログインなしで利用できます。名前・相棒（くま、うさぎ、きつね、パンダ）・いつものテントをプロフィールで選べます。未ログインでもサーバーに自動保存します。ブラウザのHttpOnly Cookieで本人の記録を識別するため、Cookieを削除すると同じ未ログイン記録は開けません。別端末への引き継ぎにはログインしてください。

ChatGPTでログインすると、本人のプロフィール・訪問記録をDBに保存し、別端末の同一アカウントに引き継ぎます。ログイン時には、そのブラウザのサーバー上の未ログイン記録を安定した訪問IDで重複なく取り込みます。手動の同期・取り込みボタンはありません。アカウントの切り替え中に別タブが古い利用者の状態を上書きしないよう、保存先IDも照合します。

訪問日は日本時間の当日が初期値で、過去の日付も選べます。天気は未記録を含む6種類、食事は6メニュー。車とタープも追加でき、どれか1アクティビティでクリアになり、テントなしの訪問や複数回の訪問も記録できます。履歴から日付・天気・メニューを編集でき、当時の相棒・テント・食事の3D表示は閲覧だけで訪問回数を増やしません。

地図は固定角度の正投影。ホイール・ピンチ・スライダーは共通のズーム状態を即時反映し、地図だけカメラの追従遅延をなくしています。ドラッグは平行移動、キャンプ場・地域・都道府県の選択時は位置とズームを900msで一緒にスライドします（OSの動きを減らす設定に対応）。全国8地域→都道府県と属性ボタンで絞り込みでき、複数属性はAND条件です。地図の余白クリックで選択を解除し、未選択時はキャンプ場カードを隠します。ズーム操作は右下、左のキャンプ場一覧は上部をコンパクトにして縦長にしています。縮小時は県ごとの件数と実施済みアクティビティへ集約し、日本全体ではエリア全体を1つにまとめます。集約を押すと拡大します。個別地点は小さな点を基本に、周囲54px以内でも最寄りのキャンプ場名を表示し、選択・ホバー・フォーカス時だけ名前を表示し、思い出の道具を隠さないようにしています。選択エリアは国土数値情報の都道府県GeoJSONを簡略化した実際の輪郭で着色し、地図上にもエリア名と件数を表示します。境界データは2019年版をゲーム向けに簡略化した表示です。直線的な矩形クリップは使用しません。

キャンプ場は半径17、道具の配置は半径13まで広げ、入口・木々・背景施設を外周側に移しています。海沿いのキャンプ場では海側の半周に木を置かず、花も陸側に置きます。過去の道具の保存座標は引き継ぎます。

テント・焚き火・ごはん・車・タープは、道具の配置パネルから地面をクリックするか、3Dの道具を直接ドラッグして配置できます。微調整・回転にも対応し、訪問ごとの位置と向きをサーバーに自動保存します。過去のキャンプは保存した配置を読み取り専用で再現します。

## ソースとDB

- `public/camp/`：ゲームのソースと静的アセット。`dist/`は生成物です。
- `app/api/camps/route.ts`：キャンプ場カタログ。D1の`campgrounds`テーブルから読み出します。
- `data/camps.json`：初期サンプル。新しいIDのみ`INSERT OR IGNORE`で登録し、既存DBの変更は上書きしません。`public/camp/camps.json`はカタログ取得失敗時の閲覧用フォールバックです。
- `app/api/account/route.ts`、`lib/account-service.mjs`：本人のプロフィールと訪問記録。
- `accounts.user_id`：Sitesが検証して付与するユーザーID。クライアント指定のIDやメールでレコードを選択しません。
- すべてのアカウントAPIレスポンスをno-storeにし、書き込みには認証、同一Origin、入力検証を適用しています。
- 保存はrevisionの楽観ロック。別端末で更新があれば409で上書きを止めます。競合時は訪問IDと更新時刻で最新の訪問をまとめ、自動で再保存します。
- 同期失敗時の変更は端末に保持し、オンライン復帰・自動再試行で保存。同期中の画面終了でも未同期状態を残します。旧v1/v2記録も初回に自動移行します。

## 開発

Node.js 22.13以上、pnpm。Sites管理のヘルパーで依存関係のインストール・ビルド・プレビュー・公開を行います。

```sh
node --test tests/*.test.mjs
npm run db:generate
npm run build
```

D1のスキーマを変えたらDrizzleの新しいマイグレーションを生成し、既適用SQLは変更しません。ローカルDBと本番DBは別です。本番はSites公開時にマイグレーションされます。

同行者・家族はプロフィールで最大5人まで登録でき、関係（家族・パートナー・子ども・友人）と4種類のキャラクターを設定できます。設定と訪問ごとの同行者スナップショットはD1へ自動保存し、過去の訪問には当時のメンバーを表示します。子どもは小さめのキャラクターになります。既存訪問に同行者を自動追加することはありません。
操作しない時間が約2秒続くと相棒が散歩・手振り・ジャンプ・体操・きょろきょろ・ひと休みをランダムに行います。同行者も歩いたり遊んだりし、手動移動中は近くに集まります。自動行動で体験完了や訪問回数は増えません。操作・配置・体験中は自動行動を休止し、夜は一緒に眠ります。中央の円形パッドは撤去しました。
地図では近接したミニチュアと選択対象を画面上で分離します。地点からの点線は表示しません。選択中の地域・県の再押下ではカメラとズームを維持し、色付けと表示対象だけを切り替えます。

PC・スマホ共通で、地図の検索一覧を左上の開閉ボタンへ、キャンプ中の操作を下部の「体験／配置／記録／視点」へ集約し、一度に1パネルだけ開きます。体験中はパネルを閉じ、配置は利用者が配置タブを開いて始めます。道具を選択した配置中は、高さ約52pxの小さな操作バーへ折りたたみ、回転・道具の切り替え・完了だけを残します。
テント・焚き火・食事・就寝などの体験では同行者全員が対象の道具の周りに集合してから一緒に動作します。配置を変えた道具にも追従します。日中の共同動作は数秒間、就寝は夜が明けるまで続きます。
地図の最短距離は28から10へ拡張（最大拡大が2.8倍）。ホイール・ピンチ・スライダーで共通の範囲を使い、距離55以下ではキャンプ場名を常時表示し、名称表示時には地点の間隔も広げます。

車の体験では入口から登録された駐車位置までベジェ曲線に沿って走行し、停止後にドアを開け、相棒と同行者が順に降車します。走行・降車中の一時座標は保存せず、完了後に車の体験と駐車位置を自動保存します。過去の再現は保存済みの駐車状態を表示します。
同行者の自由行動は約70%の判断で散歩を選ぶようにし、移動範囲と速度を拡張、休止時間を短縮しました。手動操作・配置・集合・就寝は引き続き優先します。

地図の目印・集約マーカー・キャンバスのポインター操作は同じ状態機械で処理します。目印から開始したドラッグも平行移動し、ピンチ後に指を離してもタップ選択を発火しません。中断・フォーカス離脱時は操作状態を解除します。ズームはポインター／2本指の中心を基準にし、選択中のキャンプ場への自動引き寄せを行いません。ブラウザのピンチ・ダブルタップ拡大を抑制し、アプリ側の地図ズームに集約しました。メニューの1本指スクロールは維持します。
地図のキャンプ場選択時は高さ約113pxのコンパクトバーに名前と「キャンプへ／再開／詳細・履歴」を表示します。施設情報・過去の記録は「詳細・履歴」を明示的に開いたときだけダイアログに表示します。全国の集約マーカーはタップすると県別表示まで拡大します。
