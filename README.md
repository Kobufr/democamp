# こもれびキャンプ

実在のキャンプ場をモチーフにした、かわいい3Dキャンプゲームです。

## 遊べること

- 日本の海岸線を使った立体地図と、関東・甲信越・静岡の21キャンプ場
- 地図をドラッグ・矢印ボタンで移動し、ズームスライダー・ホイール・ピンチで拡大縮小
- ファミリー・海・川・山・オート・釣り・遊具など11属性と県を組み合わせて絞り込み
- テント・焚き火・食事・就寝を自由な順番で体験（1つでクリア）
- ドーム型・ワンポール型・ロッジ型・コテージの選択
- 体験済みの道具を地図に表示
- 訪問回数・訪問日・訪問ごとの体験履歴をブラウザに自動保存
- 過去のキャンプを訪問日・宿泊タイプ・体験内容とともに登録
- 訪問ごとの3D再表示（表示だけでは訪問回数や体験記録は変わりません）
- WebGLが使えない場合のCPU描画

## ローカルで起動

Python 3がある環境で、リポジトリのルートから実行してください。

```bash
python -m http.server 8000 --directory dist
```

ブラウザで http://localhost:8000 を開きます。ES Modulesを使うため、HTMLファイルを直接開かずHTTPサーバー経由で起動してください。ビルドやnpmインストールは不要です。

## ファイル

- `dist/index.html`: 画面の構造
- `dist/style.css`: デザイン・レスポンシブ表示
- `dist/app.js`: 3Dシーン・ゲーム・記録管理
- `dist/soft-renderer.js`: CPU描画による互換表示
- `dist/camp-history.js`: 日付の検証・訪問記録・属性フィルターの処理
- `tests/camp-history.test.mjs`: 履歴・日付・フィルター・ズームのテスト
- `dist/japan-geometry.js`: 日本の海岸線データ
- `dist/vendor/`: 同梱のThree.jsとライセンス
- `.openai/hosting.json`: Sitesのホスティング設定

## データと注意事項

進捗は端末・ブラウザごとのlocalStorageに保存されます。実在のキャンプ場の地形・施設配置・宿泊タイプはゲーム向けの演出を含み、予約や現地案内には使えません。

Three.jsのライセンスは `dist/vendor/THREE-LICENSE.txt` を参照してください。日本の海岸線は、パブリックドメインのNatural Earth 1:50mデータを簡略化しています。

公開サイト: https://komorebi-camp-3d.nttd-fr-5197.chatgpt.site

## 操作と記録

地図ではドラッグが平行移動、キャンプ場内ではドラッグが視点回転になります。ズームスライダーは左が広域、右が拡大です。地図上のテント・焚き火・食事・就寝のアイコンは、これまでの訪問で体験した内容を表します。

キャンプ場の案内カードで「新しいキャンプを始める」「過去のキャンプを3Dで見る」「過去のキャンプを登録」を選べます。途中のキャンプは専用の再開ボタンから続けられます。訪問日は日本時間の今日以前の日付で登録・編集でき、日付の変更では訪問回数は増えません。以前の記録も同じlocalStorageから引き継ぎます。

属性を複数選ぶと、すべての条件に一致するキャンプ場に絞り込みます。属性は場内や隣接公園などの特徴の概要です。施設の利用条件・営業状況は各公式サイトで確認してください。

## テスト

Node.jsのある環境で実行できます。依存パッケージのインストールは不要です。

```bash
npm test
```
