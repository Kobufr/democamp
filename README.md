# こもれびキャンプ

全国の実在キャンプ場83か所をモチーフにした、非公式の3Dキャンプゲームです。地形・施設・属性・地点はゲーム向けの概略で、営業・予約情報ではありません。

## 技術構成

- ブラウザ：JavaScript ES Modules / HTML / CSS、Three.js。WebGL非対応環境にはCanvas描画のフォールバック。
- サーバー：TypeScript、Vinext、Cloudflare Workers。
- DB：Cloudflare D1（SQLite）、Drizzleでスキーマとマイグレーションを管理。
- 認証：Sites標準のChatGPTログイン。外部のGoogle OAuthを直接接続する機能は、このホスティングでは未対応です。

## 利用

ゲストはログインなしで利用できます。名前・相棒（くま、うさぎ、きつね、パンダ）・いつものテントをプロフィールで選べます。未ログインでもサーバーに自動保存します。ブラウザのHttpOnly Cookieで本人の記録を識別するため、Cookieを削除すると同じ未ログイン記録は開けません。別端末への引き継ぎにはログインしてください。

ChatGPTでログインすると、本人のプロフィール・訪問記録をDBに保存し、別端末の同一アカウントに引き継ぎます。ログイン時には、そのブラウザのサーバー上の未ログイン記録を安定した訪問IDで重複なく取り込みます。手動の同期・取り込みボタンはありません。アカウントの切り替え中に別タブが古い利用者の状態を上書きしないよう、保存先IDも照合します。

訪問日は日本時間の当日が初期値で、過去の日付も選べます。天気は未記録を含む6種類、食事は6メニュー。車とタープも追加でき、どれか1アクティビティでクリアになり、テントなしの訪問や複数回の訪問も記録できます。履歴から日付・天気・メニューを編集でき、当時の相棒・テント・食事の3D表示は閲覧だけで訪問回数を増やしません。

地図は固定角度の正投影。ホイール・ピンチ・スライダーは共通のズーム状態を即時反映し、地図だけカメラの追従遅延をなくしています。ドラッグは平行移動、キャンプ場・地域・都道府県の選択時は位置とズームを900msで一緒にスライドします（OSの動きを減らす設定に対応）。全国8地域→都道府県と属性ボタンで絞り込みできます。エリア・県はそれぞれ複数選択のOR条件、属性はAND条件です。地図の余白クリックで選択を解除し、未選択時はキャンプ場カードを隠します。ズーム操作は右下、左のキャンプ場一覧は上部をコンパクトにして縦長にしています。縮小時は実際の位置に小さな点を表示し、近接地点は間引きます。拡大すると周囲の地点や3Dミニチュアを徐々に表示します。個別地点は小さな点を基本に、簡易点の周囲22px・ミニチュアの周囲48px以内でも最寄りのキャンプ場名を表示し、選択・ホバー・フォーカス時だけ名前を表示し、思い出の道具を隠さないようにしています。選択エリアは表示中のデフォルメ地形を県ごとに分けた領域で着色し、地図上にもエリア名と件数を表示します。海岸線は地形と色付けで一致します。境界データは2019年版をゲーム向けに簡略化した表示です。直線的な矩形クリップは使用しません。

キャンプ場は半径17、道具の配置は半径13まで広げ、入口・木々・背景施設を外周側に移しています。海沿いのキャンプ場では海側の半周に木を置かず、花も陸側に置きます。過去の道具の保存座標は引き継ぎます。

テント・焚き火・ごはん・車・タープは、道具の配置パネルから地面をクリックするか、3Dの道具を直接ドラッグして配置できます。微調整・回転にも対応し、訪問ごとの位置と向きをサーバーに自動保存します。過去のキャンプは保存した配置を読み取り専用で再現します。

## ソースとDB

- `public/camp/`：ゲームのソースと静的アセット。`dist/`は生成物です。
- `app/api/camps/route.ts`：キャンプ場カタログ。D1の`campgrounds`テーブルから読み出します。
- `data/camps.json`：初期サンプル。新しいIDのみ`INSERT OR IGNORE`で登録し、既存DBの変更は上書きしません。`public/camp/camps.json`はカタログ取得失敗時の閲覧用フォールバックです。
- `app/api/account/route.ts`、`lib/account-service.mjs`：本人のプロフィールと訪問記録。
- `accounts.user_id`：Sitesが検証して付与するユーザーID。クライアント指定のIDやメールでレコードを選択しません。
- すべてのアカウントAPIレスポンスをno-storeにし、書き込みには認証、同一Origin、入力検証を適用しています。
- 保存はrevisionの楽観ロック。別端末で更新があれば409で上書きを止めます。競合時は訪問IDと更新時刻で最新の訪問をまとめ、自動で再保存します。
- 同期失敗時の変更は端末に保持し、オンライン復帰・自動再試行で保存。同期中の画面終了でも未同期状態を残します。旧v1/v2記録も初回に自動移行します。

## 開発

Node.js 22.13以上、pnpm。Sites管理のヘルパーで依存関係のインストール・ビルド・プレビュー・公開を行います。

```sh
node --test tests/*.test.mjs
npm run db:generate
npm run build
```

D1のスキーマを変えたらDrizzleの新しいマイグレーションを生成し、既適用SQLは変更しません。ローカルDBと本番DBは別です。本番はSites公開時にマイグレーションされます。

操作しない時間が約2秒続くと相棒が散歩・手振り・ジャンプ・体操・きょろきょろ・ひと休みをランダムに行います。同行者も歩いたり遊んだりし、手動移動中は近くに集まります。自動行動で体験完了や訪問回数は増えません。操作・配置・体験中は自動行動を休止し、夜は一緒に眠ります。中央の円形パッドは撤去しました。
地点の表示位置は緯度・経度を直接使用し、ズーム・移動・絞り込み中も重なり補正を行いません。地点からの点線は表示しません。選択中の地域・県の再押下ではカメラとズームを維持し、色付けと表示対象だけを切り替えます。

PC・スマホ共通で、地図の検索一覧を左上の開閉ボタンへ、キャンプ中の操作を下部の「体験／配置／記録／視点」へ集約し、一度に1パネルだけ開きます。体験中はパネルを閉じ、配置は利用者が配置タブを開いて始めます。道具を選択した配置中は、高さ約52pxの小さな操作バーへ折りたたみ、回転・道具の切り替え・完了だけを残します。
テント・焚き火・食事・就寝などの体験では同行者全員が対象の道具の周りに集合してから一緒に動作します。配置を変えた道具にも追従します。日中の共同動作は数秒間、就寝は夜が明けるまで続きます。
地図の最短距離は0.8（以前の10から最大拡大を12.5倍へ拡張）。ホイール・ピンチ・スライダーで共通の範囲を使い、距離55以下ではキャンプ場名を表示し、62を超えるまで表示モードを維持します。重なる名称は一部を省略し、選択・ホバーした名前は優先します。名称の表示有無によって地点やミニチュアは移動しません。

車の体験では入口から登録された駐車位置までベジェ曲線に沿って走行し、停止後にドアを開け、相棒と同行者が順に降車します。走行・降車中の一時座標は保存せず、完了後に車の体験と駐車位置を自動保存します。過去の再現は保存済みの駐車状態を表示します。
同行者の自由行動は約70%の判断で散歩を選ぶようにし、移動範囲と速度を拡張、休止時間を短縮しました。手動操作・配置・集合・就寝は引き続き優先します。

地図の目印・キャンバスのポインター操作は同じ状態機械で処理します。目印から開始したドラッグも平行移動し、ピンチ後に指を離してもタップ選択を発火しません。中断・フォーカス離脱時は操作状態を解除します。ズームはポインター／2本指の中心を基準にし、選択中のキャンプ場への自動引き寄せを行いません。ブラウザのピンチ・ダブルタップ拡大を抑制し、アプリ側の地図ズームに集約しました。メニューの1本指スクロールは維持します。
地図のキャンプ場選択時は高さ約113pxのコンパクトバーに名前と「キャンプへ／再開／詳細・履歴」を表示します。施設情報・過去の記録は「詳細・履歴」を明示的に開いたときだけダイアログに表示します。

地図の地点は緯度・経度から直接配置し、ズームによって地理的位置を補正しません。近接地点は固定順で間引くため、拡大すると既存の点を保ちつつ周囲の点が現れます。ラベルが重なるときは位置を変えず一部を省略します。
体験の並び順は「車→テント→タープ→焚き火→食事→ねる→帰る」。テントの種類と食事メニューは体験パネル内のサブビューで選び、「体験一覧」ボタンで戻れます。選択して体験が始まるとパネルが閉じます。モーダルダイアログは使用しません。

### 地図表示と入退場

地図のキャンプ場はカタログの緯度・経度から直接配置し、重なり回避による位置移動は行いません。遠景は小さな点、近景は画面内だけ遅延生成する3Dミニチュアです。近接点は固定の優先順と画面上の距離で間引き、拡大すると徐々に表示されます。地図が静止している間はキャンプ場のレイアウト計算と再描画を停止します。

新しい訪問は同行者全員が入口付近（z=12.6〜13.5）へ入る2秒の演出で始まり、中央までは歩きません。再開と過去の再現では繰り返しません。体験一覧の最後の「帰る」だけが道具を片付け、徒歩または駐車済みの車で入口へ退場します。設営済みの道具は演出中のみ縮小し、保存済みの体験・レイアウトを消さないため過去のキャンプを再現できます。

天気と季節の演出は記録された訪問日・天気から生成します。春（3〜5月）は花びらと花、夏（6〜8月）は濃い緑、秋（9〜11月）は紅葉と落ち葉、冬（12〜2月）は淡い草木です。晴れ／晴れ時々くもりは太陽と少なめの雲、くもりは厚い雲、雨は雨粒と湿った地面、雪は降雪と雪化粧を表示します。冬だけを理由に積雪は強制せず、記録の「雪」を優先します。記録の編集時に即時更新し、過去のキャンプにも同じ設定を再現します。季節はゲーム共通の月別表現で、現地の実際の気候・標高による予測ではありません。降水と花びらは軽量な点バッファで描画し、WebGL・CPUの両方に対応します。OSの動きを減らす設定では粒子を静止させます。

地図メニュー・戻るボタン・記録から地図に戻る操作は帰宅演出を実行しません。入場演出中でも地図へ戻れます。最大ズーム付近でも地面に隠れない位置にミニチュアを配置し、背景の補助的な山は近景では隠します。

### 開始設定・行きたい場所・就寝

キャンプ場選択カードと詳細画面に訪問日・天気・同行者を常設しました。初期値は日本時間の当日・晴れ・プロフィール登録メンバーで、「この設定でキャンプへ」を押すだけで従来と同じ2操作（キャンプ場選択→開始）で進めます。同行者は今回だけのオン／オフ・名前とキャラクターの追加ができ、最大5人のスナップショットを訪問に保存します。記録メニューからの後日の編集も可能です。

訪問記録の一覧は1つ以上体験した訪問のあるキャンプ場だけを表示します。「行きたい」は選択カードのハートで切り替え、地図の一覧とラベルにも表示し、専用ボタンで絞り込めます。未訪問でも登録可能で、訪問回数には加えません。D1の記録JSONに独立したフラグと更新日時を保存し、端末間競合とゲスト移行でも新しいチェック／解除を維持します。

テント・コテージがある時の就寝では、回転・移動後の入口まで全員が歩いて順に入り、外側にはキャラクターを表示しません。次の体験・昼表示では外へ戻ります。テントなしの場合は屋外での就寝を維持します。夜の星は視点に追従する背景の点群として、雨は190本の移動する線分としてWebGLとCPUの両方で描画します。

### 地形と選択色の共通輪郭

`deformed-prefectures.js` は現在の `japanIslands` の陸地を分割して生成します。海岸線を変更せず、内陸の県所属はN03-2019を参考に約0.12度以下の三角形で判定し、同じ県の三角形を結合します。47都道府県の領域を合わせると表示地形全体と一致します。着色面の高さも地形の上面と同じにし、拡大時の浮き上がりによるずれを防ぎます。生成は `node scripts/build-deformed-prefectures.mjs`、描画時の分割処理は不要です。ゲームのデフォルメに合わせた県境であり、測量・行政境界の確認用ではありません。

右下の「キャンプエリア／日本全体」スイッチを削除しました。移動・拡大縮小・エリア／県の複数選択は引き続き利用できます。

### 体験・食事の追加と地図の目印

体験は従来の6種類に「遊ぶ・泳ぐ・釣り・歌う・歩く・お風呂」を加えた12種類です。同行者全員で集合し、ボール遊び、水あそび用のプール、釣り竿、音符、おさんぽ、湯気の出るお風呂をゲーム内で演出します。これらのうち1つだけでもキャンプ場クリアとなり、D1保存・履歴・過去の再現に対応します。演出のプールやお風呂は実在施設の設備・営業状況を表すものではありません。

食事は体験パネル内で「ごはん・朝ごはん・昼ごはん・夜ごはん・おやつ」を任意に選べます。同じ訪問に複数回の食事を追加し、各メニューを `meals` 配列に保存します。以前の `mealMenu` だけの記録も保持し、追加時に引き継ぎます。食事の回数を増やしてもキャンプ場の訪問回数は増えません。履歴にはすべての時間帯とメニューを表示します。

キャンプ場は「行きたい＝金色・訪問済み＝青緑・両方＝紫」で地図の点・名前の吹き出し・ミニチュアの台座・検索行を色分けし、記号と文字も併記します。未訪問は従来の色です。

富士山はズームで隠す装飾グループから分離しました。地図の目印として犬吠埼灯台・華厳滝・白糸ノ滝・浅間山・男体山も追加。表示サイズを18〜65pxの範囲に調整し、近景でもキャンプ場を覆いすぎず残ります。位置はゲーム用の概略です。参照した自治体・観光協会等の公式ページは `map-landmarks.js` とサイト内「この世界について」に記載しています。


### 地図・検索の整理とサンプル拡充

キャンプ場を60か所追加し、DB初期データとオフライン用カタログをともに143か所にしました。既存IDと記録は維持し、D1は既存の `INSERT OR IGNORE` により追加IDだけを投入します。今回の名称・所在地の参照元は長野県公式観光サイト、北海道オートキャンプ協会、千葉県の公立キャンプ場一覧、群馬県「ぐんまdeキャンプ」、那須野が原公園公式サイトです。各エントリーの `url` に参照元を持たせています。座標はゲーム地図用の概略位置、属性と地形は周辺の環境をもとにしたサンプルです。営業情報や予約可否は扱いません。

観光オブジェクトは36か所。灯台・滝・名山に加え、城・寺院・鳥居・タワー・大仏を低ポリゴンで表現します。地図の観光地名・島名は表示せず、参照先は「この世界について」に残しています。ズームアウト時は重なる観光オブジェクトを位置をずらさず間引き、ズームインすると現れます。

検索条件を標準で閉じた1つの開閉パネルにまとめ、選択中の条件を要約表示します。条件を開いた場合も内部スクロールと高さ制限により結果一覧の領域を残し、地域・県・属性の複数選択を維持します。

県境は共有する内陸の点を同時に平滑化し、海岸線と3県以上の接点を固定します。陸地全体の一致、隙間・重なり、三角形分割の面積をテストします。雨は移動する線分で毎フレーム下へ落ち、動きを減らす端末設定でも40%の速度で動きます。他の季節の粒子はその設定に従い静止します。


### タップでわかる観光地と変化する体験

地図の全国／選択範囲の件数チップは非表示にし、キャンプ場名の状態色は枠線なしにしました。観光オブジェクトは通常は名前を出さず、タップするとその場所に小さな名前を表示します。名前は閉じるボタンか空白タップで消え、地図移動に追従します。滝は崖・白い水筋・滝つぼと泡を組み合わせた形に変更しました。空白を340ms以内・28px以内で2回タップすると、その位置を基準にズームします。ドラッグ・ピンチ・キャンプ場／観光地タップはダブルタップの判定をリセットします。

新しい訪問では4つの配置テンプレートを訪問回数に応じて切り替えます。入口、水辺、外周の木を避け、テント・焚き火・食事・タープ・車の間隔を保つ候補です。テントの再設営では配置済みの道具との間隔を検証し、別の安全な候補があれば位置を変えます。候補がふさがっている場合は配置を維持します。屋外体験も道具との距離を検証し、空きがなければ配置を広げる案内を表示します。各体験の動き・速度・所要時間も4パターンを切り替え、同行者も同じ体験に参加します。`activityCounts` と最後の屋外体験位置を保存するので、再開・別端末・過去再現でも配置が勝手に再抽選されません。手動の配置操作も引き続き利用できます。


### 中心を向くカメラ・手動移動・夕方と朝

キャンプ場のカメラは体験・入退場・車の到着中も原点を注視します。体験による視点中心やズームの上書きを外し、ドラッグでの回転と手動ズームは維持します。屋外体験の自動候補はテント中心から7以上離し、他の道具との余白や水辺の条件も検証します。

地面タップ・WASD／矢印キーで指定した場所は次の体験まで保持します。その体験は手動指定位置で開始し、道具が必要なら同じ位置に配置します。屋外体験の開始位置も保存対象です。狭い・水辺・外周に近いなどの理由で配置できない場合は勝手に別の場所へ移さず案内します。設営済みテントでの就寝はテント集合を優先し、テントなしなら手動位置で寝られます。

就寝を選ぶと集合中に夕方の空と低い夕日に変化し、全員がテントに入った後に夜と星空へ移ります。就寝中に別の体験・配置・帰宅を選ぶと、朝日が低い位置からのぼり、全員が起床してから行動を続けます。空・照明・太陽・星を時間で補間するため、急な色の切り替えを避けています。天気・季節の記録は変更しません。
